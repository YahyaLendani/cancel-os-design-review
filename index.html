Cancel OS

Design review: premium identity, first slice

The oat and ivory palette, the cut-tile logo, the brand loader and calmer motion. Every screen uses synthetic test data (account wizard@example.test, services named "Synthetic …") on a local stand-in server, in headless Chrome or the Android emulator. No real person's data appears.

This is a public preview. Anyone with the link can open it. It asks search engines not to index it, but that is a request, not access control.

Revisions are commits in the private Cancel OS repository. Design checkpoint: 936a9fe (code) and 75668e9 (its evidence). The "Most popular" badge was removed in eefb0e8, with evidence in cb709fc.
